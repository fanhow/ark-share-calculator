# 布局運算機 v1.1.0

依觀察到的方舟運算流程，先算配置差額，再換算任意股票的股數、整張、零股及預估價金。網站：https://fanhow.github.io/ark-share-calculator/

- **風控配置**：輸入同幣別的台股／美股庫存市值、原幣台幣／美元現金與手動目標比例 R，算出布局、調節或維持。只有正布局金額能帶入下一步。修改第一步會清除已帶入的舊預算。
- **預算換算**：總布局預算 ÷ 分配檔數 ÷ 每股價格，再向下取到交易單位。採精確十進位分式。
- **方舟股數公式**：總布局預算 ÷（分配檔數 × 每股價格 × max(1, 策略 K9)），再截斷至股數精度。K9 由使用者提供，空白不會預設為 1。
- 支援台股 TWD、美股 USD、手動換匯與交易單位。輸入僅在記憶體運算，不用帳戶、不儲存或傳送試算資料；CSV 由使用者主動下載。

## 適用範圍

此為獨立研究工具，非方舟官方產品。公式來自合法取得之 Android com.galaxy.ark 1.9.2.0 / versionCode 56 的本機靜態分析，研究歸檔日 2026-10-15。沒有執行 APK。原始 APK、反編譯內容、鏡像畫面、私人研究與帳戶資料均未包含在此儲存庫。

策略 K9、價值／升溫名單與持股水位建議的上游生成公式尚未確認。一般 K/D 與策略 K9 未證明相等，計算器不自行產生 K9 或選股建議。沒有完整 App 同次真實輸入／輸出驗證，不能宣稱與現行 iPhone App 完全相同。

配置核心依 Android 順序重建：換匯後現金先按幣別進位；R/100 使用 HALF_UP 保留10位；總資金乘該比例後按幣別進位；目標現金向零取2位；現金差額再按幣別取整。庫存輸入限制為已換成試算幣別的顯示值：TWD整元、USD兩位。R限制0–100%屬本工具規則，並非宣稱APK有同樣限制；有效0%與空白分開。iPhone顯示樣本與Android重建目標持股仍有1元差，可能涉及版本或顯示精度，原因未確認；不宣稱逐項一致。

已重建的正常股數路徑先將價格轉成 float32，再以精確分式處理。一般台股使用整股、美股保留兩位，均向零截斷；正布局金額依顯示 TWD/ USD 分別進位至整元／兩位小數。Android 原精度判斷還接受特定交易時段 metadata；此頁僅服務明示的普通台股／美股，不宣稱涵蓋所有商品。跨幣別模型中 TWD→USD 的匯率倒數向零取至 100 位；預估交易價金則使用輸入十進位價格與精確匯率。

交易單位是這個計算器的額外功能。實際可買股數依公式股數、十進位預算上限兩者較小值，再向下取單位；金額未含費用。原始公式股數與模型顯示金額會另列，避免混淆預估價金。

頁面拒絕負數／空白價格與預算、非整數檔數、無效格式及台股非整股單位；這些是工具輸入約束，並非宣稱 APK 有相同驗證。無效輸入會清除輸出。每筆輸入最多 16 位整數、12 位小數；交易單位 0.000001–1,000,000，檔數 1–100,000。

## 開發與驗證

沒有套件依賴。使用 Node.js 18+：

```sh
npm test
python3 -m http.server 8000
```

在 http://localhost:8000 查看。測試包含 float32 邊界、K 下界／無上界截限、兩向換匯、股數精度與顯示幣別交叉、整張下單、無效輸入、精確大數及 500 組不超預算檢查。新增配置正負零、R缺值、兩向現金換匯、大小數進位與大數精度測試，共26個單元案例；瀏覽器另驗證步驟連動、失效預算清除及320/375px版面。這些是重建程式與公開工具測試，非實機 App 驗收。

GitHub Pages 從 `main` 根目錄部署；`.nojekyll` 關閉 Jekyll。價格與匯率由使用者提供，不含行情服務或券商連線。
